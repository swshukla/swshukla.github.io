Privacy policy

Effective 25 November 2026

VideoForge is a private, single-user tool that publishes the Null Pointer channel's own videos. It is used only by its operator, on the operator's own computer, with the operator's own accounts. This policy explains what account data it accesses and what it does with it.

YouTube API Services

VideoForge uses YouTube API Services. By using VideoForge you agree to be bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

What it accesses

When the operator signs in with Google, VideoForge asks for these permissions on the operator's own YouTube channel:

  • Manage your YouTube videos (youtube.upload): to upload approved videos and Shorts.
  • See, edit and delete your YouTube videos, ratings, comments and captions (youtube.force-ssl): to add captions and thumbnails, add videos to playlists, check whether an upload is public, and read which channel the sign-in belongs to, so videos never go to the wrong channel.

VideoForge does not read, change or delete ratings or comments, does not delete videos, and does not access any other user's channel or data.

For Instagram and X, VideoForge likewise uses only the operator's own accounts, to publish the channel's own Reels and posts.

How the data is stored

Sign-in tokens are stored only on the operator's computer, in files readable only by the operator's user account. VideoForge has no server and no database, and it sends account data nowhere except to the platform it belongs to (Google's servers for YouTube, Meta's for Instagram, X's for X).

Sharing

VideoForge does not sell, share, transfer or disclose any account data to anyone. It shows no advertising and does not use the data to train AI or machine-learning models.

Google API Services User Data Policy

VideoForge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page (and the equivalent settings on Instagram and X). Deleting VideoForge's local token files removes every copy of the stored sign-in; nothing is kept anywhere else. Data obtained from the YouTube API is not stored beyond what each upload needs (the uploaded video's ID and link).

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
