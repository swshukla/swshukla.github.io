video-forge

video-forge (also written VideoForge) is a private, single-user publishing tool for the Null Pointer YouTube channel, which publishes educational explainer videos about software engineering and large-scale systems. It runs on its operator's own computer and acts only on the operator's own accounts. It is not offered to the public and has no sign-up.

Purpose

When the operator has finished and personally approved an episode, video-forge publishes it so it does not have to be uploaded by hand:

  • YouTube: uploads the episode's long video and its Shorts to the operator's own channel, with the title, description, tags, thumbnail, captions and playlist the operator wrote.
  • Instagram: posts the approved Shorts to the channel's own Instagram account as Reels.
  • X: posts short text insights from the episode, each with a diagram from the video and a link to it, to the channel's own X account on a schedule.

How it uses Google user data

video-forge signs in to the operator's own Google account with the YouTube Data API and uses that access only to:

  • upload the operator's approved videos and Shorts, and set their thumbnails and captions;
  • find or create the channel's playlists and add uploaded videos to them;
  • check whether an uploaded video is public yet;
  • read the signed-in channel's ID and name, so uploads can never go to the wrong channel.

It does not read anyone else's data, does not read or change comments or ratings, does not delete videos, and does not share Google user data with anyone. Details are in the privacy policy.

What it does not do

video-forge does not generate, edit or upload images or video of real people. The videos it publishes are the channel's own finished explainers: diagrams, charts and narration about technical topics. It is never used to create or distribute sexual, intimate or non-consensual imagery of anyone, including AI-generated imagery.
