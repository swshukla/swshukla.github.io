video-forge privacy policy

Effective 25 November 2026

video-forge (also written VideoForge) is a private, single-user tool that publishes the Null Pointer channel's own approved explainer videos to the operator's own YouTube, Instagram and X accounts. It runs only on the operator's own computer. This policy describes what data video-forge accesses, why, how it is stored and protected, how long it is kept, and how to remove it.

1. YouTube API Services

video-forge uses YouTube API Services. By using video-forge you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Data video-forge accesses

video-forge accesses only the operator's own accounts. From Google it requests two YouTube permissions on the operator's channel:

  • Manage your YouTube videos (https://www.googleapis.com/auth/youtube.upload): used to upload the operator's approved videos and Shorts.
  • See, edit and permanently delete your YouTube videos, ratings, comments and captions (https://www.googleapis.com/auth/youtube.force-ssl): used to add captions and a thumbnail to each uploaded video, find or create playlists and add videos to them, check whether an upload is public, and read the signed-in channel's ID and name.

With this access video-forge reads or writes only the following:

  • Sign-in tokens (OAuth access and refresh tokens) issued by Google, so it can act without asking the operator to sign in each time;
  • the signed-in channel's ID and name, checked before every upload so videos never go to the wrong channel;
  • the IDs and links of videos it uploads, and those videos' privacy status, so it knows what has been published;
  • the channel's playlist names and IDs, to add videos to the right playlist.

video-forge does not read, change or delete comments or ratings, does not delete videos, and does not access any viewer's data or any other user's channel. It does not collect names, email addresses, contacts, location, payment details or any other personal information.

3. How the data is used

The data above is used only to publish the operator's own videos as described, and for no other purpose. video-forge does not use Google user data for advertising, does not sell it, and does not use it to develop, improve or train AI or machine-learning models.

4. Sharing and disclosure

video-forge does not share, transfer or disclose Google user data to any third party. Data is sent only to the platform it belongs to: to Google when uploading to YouTube, to Meta when posting to Instagram, and to X when posting to X.

5. Google API Services User Data Policy

video-forge's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Storage and security

video-forge has no server and no database. Sign-in tokens are stored only on the operator's own computer, in files that only the operator's user account can read (file permission 0600, in a folder with permission 0700). The IDs and links of published videos are kept in local files next to each episode. All communication with Google, Meta and X uses HTTPS.

7. Retention and deletion

Sign-in tokens are kept until the operator signs out by revoking access or deleting the token files. Video IDs and links are kept as a record of what has been published, for as long as the episode's files are kept. To remove everything:

  • revoke video-forge's access at myaccount.google.com/permissions (and in the Instagram and X app settings);
  • delete video-forge's local token files. No copy exists anywhere else, so deleting them removes the data completely and immediately.

8. Children

video-forge is a private tool used only by its adult operator. It is not directed at children and collects no data from anyone other than the operator.

9. Changes to this policy

Any change will be posted on this page with a new effective date.
